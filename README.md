# りんりん日和

HTML・CSS・JavaScript を1ファイルにまとめ、Canvas で作った、かわいい自転車の横スクロールゲームです。ビルドや npm パッケージのインストールは不要です。

## Windowsでダウンロードして遊ぶ

1. 完成した `index.html` をダウンロードして、任意のフォルダーに保存します。他のファイルは不要です。
2. `index.html` をダブルクリックします。既定のブラウザでゲームが開きます。
3. 「サイクリングをはじめる」をクリックし、スペースキーでジャンプしてください。

インストールやインターネット接続、ローカルサーバーは不要です。テキストとして開いてしまう場合は、右クリック →「プログラムから開く」で Edge または Chrome を選んでください。手動で保存するときは `index.html.txt` ではなく `index.html` にしてください。

## GitHubからindex.htmlだけをダウンロードする

このファイルがGitHubにコミット・プッシュされた後、次の手順で取得できます。ローカルの保存だけではGitHubには反映されません。

1. https://github.com/komiki0401/chari-game を開き、完成版を反映したブランチを選びます（`main` に反映済みなら `main`）。
2. ファイル一覧の `index.html` をクリックします。
3. ファイル表示欄の右上にある「Download raw file」（下向き矢印）をクリックします。
4. 保存した `index.html` をダブルクリックし、EdgeまたはChromeで遊びます。

ダウンロードボタンが見つからない場合は「Raw」を開き、`Ctrl+S` で保存してください。ファイル名は `index.html`、ファイルの種類は「すべてのファイル」にします。GitHubのファイル一覧ページ自体を保存しないでください。リポジトリが非公開の場合は、アクセス権のあるGitHubアカウントでログインが必要です。

## 起動方法

`index.html` をブラウザで開いてください。または、このディレクトリで以下を実行し、ブラウザで `http://localhost:8000` を開きます。

```sh
cd /workspace/chari-game
python3 -m http.server 8000
```

別の場所にダウンロードした場合は、そのディレクトリでサーバーを起動してください。終了は `Ctrl+C` です。

## 遊び方

- 「サイクリングをはじめる」またはスペースキーで開始。
- 自転車は自動で右方向へ走ります。
- スペースキー、またはゲーム画面のタップでジャンプ。着地後に次のジャンプができます。
- 石やコーンを避け、走行距離（m）を伸ばしましょう。少しずつ速度が上がります。
- 障害物にぶつかるとゲームオーバー。「もういちど走る」、スペースキー、または「リスタート」で再挑戦できます。
- ベスト記録はブラウザの localStorage に保存します。保存が許可されていなくてもゲームは動きます。

## ファイル

- `index.html`：画面、CSS、ゲームのJavaScriptをすべて含む自己完結型のファイル。編集する場合もこのファイルを変更します。

最新の Chrome・Edge・Firefox・Safari を想定しています。端末の標準フォントを使用します。外部通信・画像・ゲームライブラリ・APIキーは不要です。

## プレビューで開く場合

`index.html` 全体をHTMLプレビューで開いてください。相対パスのCSSやJavaScriptを読み込まないため、HTML単体や `iframe srcdoc` でも動きます。ゲームの開始ボタンを押すと操作対象にフォーカスが移り、スペースキーでジャンプできます。

プレビューはJavaScriptとCanvasの実行を許可している必要があります。実行禁止のプレビューでは、ファイルを通常のブラウザで開くか、上記のHTTPサーバーを使ってください。埋め込み環境で保存機能が制限されていても遊べますが、ベスト記録は次回まで保存されない場合があります。
